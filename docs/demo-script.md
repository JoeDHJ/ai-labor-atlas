# Two-minute demonstration

Preparation: `atlas build --demo; atlas research; atlas serve` for a fully offline
demonstration. For the actual findings below, use the public-source build instead
of `--demo`. The homepage clearly identifies a synthetic occupation demo.

**0:00–0:25 — The decision.** Open the research homepage. Explain that workforce
teams need three different measurements: occupational AI applicability, actual
recruitment conditions and the skills used in the work. Point to the $88,489 versus
$45,686 wage comparison and its 691-SOC sample; explain that it describes where
high-wage workflows sit, without estimating an AI wage effect.

**0:25–0:50 — Market pulse.** Switch from openings to employment, then pay.
The same January 2022–September 2026 window shows sharply lower vacancies,
slightly higher payrolls and higher nominal wages. These series cannot be used
interchangeably to claim that AI has removed jobs.

**0:50–1:15 — Skills behind the aggregate.** Select the professional/business
services industry, then manufacturing. Show the different skill importance
profiles and their staffing coverage. Explain that the combined critical-thinking
and active-listening share is descriptive co-occurrence. Open the occupation
explorer to inspect a task statement and the Career bridge's exact profile evidence.

**1:15–1:45 — A decision under assumptions.** Return to Scenarios. Run the
default 1,000-person, three-year case. Year-3 net annual capacity is 129,594 hours;
show the slower/faster adoption comparison. Change training effectiveness or task
share and rerun. Explain which parameters a workflow pilot should measure.
Headcount remains the baseline; FTE equivalent is a unit of released time.

**1:45–2:00 — Delivery and reproducibility.** Download the Markdown brief, a
structured case table and the scenario JSON. Show `atlas research` as the command
that regenerates the cases and the versioned snapshot as the handoff to other
portfolio projects. All source dates, units, mappings and coverage remain inspectable.
